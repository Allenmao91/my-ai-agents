02 · 操作

如何训练这个网络

页面加载时参数是随机初始化的，所以一开始决策边界几乎是一团乱色。按下面的顺序操作，你能亲眼看到它从「瞎猜」变成「会判断」。

  1. 先看初始状态。左侧背景几乎均匀、散点分布与颜色对不上，说明随机权重还没有学到任何规律；右侧四个热力图颜色杂乱无章。
  2. 点一次「单步迭代」。这一次完成了完整的一轮：前向传播算预测 → 二元交叉熵算损失 → 反向传播算梯度 → 梯度下降更新参数。观察迭代次数变 1、损失出现在 0.69 附近、热力图颜色略微变化。
  3. 点「开始训练」连续跑。默认每帧 50 步，损失会快速下降后逐渐趋缓；左侧背景开始分成清晰的青色与紫色区域，右侧热力图形成稳定的明暗格局。再点一次可暂停。
  4. 判断收敛。当损失长时间不再明显下降、准确率稳定，就说明训练接近收敛。此时决策边界基本把「去」和「不去」分开了。
  5. 做对比实验。重置后用不同超参数各训练一次：隐藏神经元 2 时边界过于简单（欠拟合）；8~12 时边界更弯曲，甚至开始贴合噪声；学习率 0.01 收敛很慢，0.5 以上容易震荡；激活函数选 ReLU 会得到折线状边界，tanh 更平滑。
  6. 重复训练。点「重置参数」会重新随机初始化权重。同一组超参数多跑几次，最终边界不会完全相同——这是随机初始化带来的正常差异。

提示：单步迭代适合观察「一次参数更新到底改了什么」；连续训练适合观察「决策边界如何成形」。两者配合使用效果最好。

03 · 演练

用两条演示数据走一遍训练

下面用一组手工设定的初始参数和 2 条样本，完整演算一次迭代。页面实际使用随机初始化和 160 条样本，数值不会相同，但计算流程完全一致。

演示数据（2 条样本）

样本心情 x₁天气 x₂真实标签 y现实含义
①0.80.91心情好、天气好 → 去
②-0.6-0.50心情差、天气差 → 不去

网络结构：2 输入 → 2 个隐藏神经元（tanh） → 1 输出（sigmoid），学习率 η = 0.1。初始参数手工设定为：

W₁ = [[0.5, -0.3], [0.2, 0.4]]　　b₁ = [0.1, -0.1]
W₂ = [0.6, -0.5]ᵀ　　b₂ = 0.05

第 1 步 · 前向传播（算预测）

// 样本 ① 心情 0.8，天气 0.9
z₁⁽¹⁾ = 0.5×0.8 + 0.2×0.9 + 0.1 = 0.680
z₁⁽²⁾ = -0.3×0.8 + 0.4×0.9 − 0.1 = 0.020
a₁ = tanh(0.680), tanh(0.020) = 0.592, 0.020
z₂ = 0.6×0.592 + (−0.5)×0.020 + 0.05 = 0.395
ŷ = sigmoid(0.395) = 0.598　→ 预测 59.8% 会去，真实是「去」
// 样本 ② 心情 -0.6，天气 -0.5
z₁ = -0.300, -0.120　→　a₁ = -0.291, -0.119
z₂ = 0.6×(−0.291) + (−0.5)×(−0.119) + 0.05 = -0.065
ŷ = sigmoid(−0.065) = 0.484　→ 预测 48.4% 会去，真实是「不去」

第 2 步 · 计算损失

L₁ = −ln(0.598) = 0.515　　L₂ = −ln(1 − 0.484) = 0.661
L = (0.515 + 0.661) / 2 = 0.588　（两条样本的平均交叉熵）

第 3 步 · 反向传播（算梯度）

// 输出层误差，N = 2
δ₂ = (ŷ − y)/N　→　样本① -0.201，样本② +0.242
// 输出层权重梯度 = 隐藏层输出 × 输出层误差
∂L/∂W₂¹ = 0.592×(−0.201) + (−0.291)×0.242 = -0.190
∂L/∂W₂² = 0.020×(−0.201) + (−0.119)×0.242 = -0.033
∂L/∂b₂ = (−0.201) + 0.242 = +0.041
// 隐藏层误差 = 输出层误差回传 × tanh 导数 (1 − a₁²)
δ₁ 样本① ≈ -0.078, +0.100　样本② ≈ +0.133, -0.119
∂L/∂W₁ = 输入 × δ₁ 累加 → -0.142, -0.137, +0.151, +0.150
∂L/∂b₁ = +0.055, -0.019

第 4 步 · 梯度下降（更新参数）

// 规则：新值 = 旧值 − 学习率 × 梯度
W₂ = 0.6 − 0.1×(−0.190) = 0.619　　−0.5 − 0.1×(−0.033) = -0.497
b₂ = 0.05 − 0.1×0.041 = 0.046
W₁ = 0.514, 0.214, -0.315, 0.385
b₁ = 0.095, -0.098

第 5 步 · 一轮之后的效果

样本① ŷ：0.598 → 0.604　（更接近 1，方向对了）
样本② ŷ：0.484 → 0.476　（更接近 0，方向对了）
平均损失：0.588 → 0.575　↓ 0.013

一次更新只让损失下降约 0.013，参数几乎没变。这正是页面上需要成百上千次迭代的原因：学习是「一小步一小步挪」出来的，不是一步到位。

04 · 边界

这个模型的局限与数据的特殊性

热力图很好看，但要清楚它证明了什么、没证明什么。下面两点决定了你应该如何解读页面上出现的数字。

模型本身的局限

  • 容量有限：只有 1 个隐藏层、最多 12 个神经元，能画出弯曲边界，但应付不了螺旋这类高度复杂的分布。
  • 对初始化敏感：权重随机初始化，同样超参数两次训练得到的结果不完全一致。
  • 对学习率敏感：太大震荡甚至发散，太小则收敛极慢。
  • 全批量梯度下降：每一步都用全部 160 条样本，数据量大时非常慢；实际训练通常用 mini-batch。
  • 没有正则化：隐藏神经元过多时，模型会把噪声也记住，出现过拟合。
  • 只支持二分类：输出层是 sigmoid；多分类需要改成 softmax + 多输出。
  • 准确率只是训练集准确率：页面没有划分验证集/测试集，不能据此判断泛化能力。
  • 输入已归一化：心情与天气都被压到 [-1, 1]；真实数据需要先做标准化，否则训练会很不稳定。

演示数据的特殊性

  • 人工规则生成，不是真实采集：心情与天气同号时结果确定（都好 → 去，都差 → 不去）；异号时由天气主导——天气好则 70% 去，天气差则 70% 不去。核心是一个接近 XOR 的非线性问题。
  • 规模很小：2 个特征、160 条样本，均匀分布在 [-1, 1]² 内，纯粹为了能画成二维图。
  • 标签含 30% 随机翻转：两个「一好一差」的象限里，有 30% 的标签是随机反的。这部分噪声无法被任何模型学会。
  • 准确率上限约 85%：两个确定象限（各 25%）全对，两个不确定象限（各 25%）只能对 70%，即 0.25 + 0.25 + 0.175 + 0.175 = 0.85。若准确率明显超过 85%，说明模型在「背」噪声，是过拟合的信号。
  • 无缺失、无异常值、类别大致均衡：省去了真实数据清洗的麻烦，也因此不能代表真实场景的难度。
  • 不能外推到真实行为：现实中「去不去健身房」还受时间、同伴、身体状况等影响，这套二维规则只是教学简化。

正确的解读方式：页面上决策边界的成形，证明的是「前向传播 + 反向传播 + 梯度下降」这套机制能让参数朝着正确的方向移动；它不证明模型适用于真实决策，也不代表 85% 以上的准确率是「更好」。
