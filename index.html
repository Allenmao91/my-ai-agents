02 · MLP 学习成果

人工智能概论 · MLP 学习参数

课程作业：不调用任何机器学习框架，用纯 JavaScript 手写多层感知机，并把参数学习过程完整可视化。

决策边界 + 权重热力图训练可视化

SCENE / 健身房决策 · 输入：心情 × 天气 · 输出：去 / 不去

训练时同时呈现两件事：左侧决策边界如何从一片混乱逐渐分出清晰的「去 / 不去」区域；右侧 W₁、b₁、W₂、b₂ 四个参数矩阵的热力图如何随梯度下降不断更新。参数究竟学到了什么，一眼可见。

实现要点

  • 前向传播：z₁ = XW₁ + b₁ → a₁ = σ(z₁) → z₂ = a₁W₂ + b₂ → ŷ = sigmoid(z₂)
  • 损失函数：二元交叉熵，衡量预测与真实的差距
  • 反向传播：链式法则逐层求梯度，误差从输出层回传到隐藏层
  • 梯度下降：按学习率更新全部权重与偏置

可调参数

  • 隐藏神经元数：2 ~ 12，观察欠拟合与拟合能力
  • 学习率：过大震荡、过小收敛慢
  • 激活函数：tanh / ReLU / sigmoid
  • 训练速度：单步迭代或连续训练
